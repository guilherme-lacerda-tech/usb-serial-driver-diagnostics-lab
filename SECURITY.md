# Security Policy

## Supported Versions

The `main` branch and the latest release receive security fixes.

## Data Safety

This project is intentionally synthetic. Do not submit real customer logs, corporate endpoints, private APNs, credentials, internal commands, device serial numbers, IMEI, ICCID or screenshots from non-public systems.

## Reporting a Vulnerability

Open a private security advisory on GitHub or contact the repository owner through GitHub. Include a minimal reproduction using synthetic data.
